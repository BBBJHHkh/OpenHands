# KKSJB05P001_不足情報リスト

対象：バッチ仕様書（KKSJB05P001_利用者控連携処理）.xlsx（写真復元版）から Java コードを生成するために、本書以外から必要となる情報の一覧
作成日：2026/10/19

## 0. 目的と読み方

- 本リストは、バッチ仕様書（KKSJB05P001_利用者控連携処理）（以下「本書」）に**名前が現れるが定義が書かれていない**ものを、本書の全20シートから漏れなく抽出したものである。
- 本書には処理の流れ、メソッド構成、編集項目（項目単位の設定仕様）、ログ出力仕様まで書かれているため、ジョブ本体の処理ロジックは本書だけで生成できる。一方で、本リストの項目が揃わないと、生成コードはコンパイルできない（参照先の型・値・API が存在しないため）。
- 各項目の「本書で判明していること」は本書の記載そのまま、「不足情報」は本書のどこにも書かれていないことだけを挙げている。推測で補った項目はない。
- 本書自体の表記の確認事項（原文のまま収録した箇所）は、別ファイル KKSJB05P001_転記注記.md の4にまとめている。本リストとは分けて扱うこと。


### 出現箇所の表記について（2026/10/19 追記）

- 各節の末尾に「出現箇所」として、本書の全シートから抽出した出現行を、シート名／Excel 行番号／その行の内容（復元版のセルを「 | 」で連結したもの）で全件列挙した。
- 行番号は復元版 Excel の行番号であり、原本の Excel 行番号と一致する。位置の特定はこのシート名と行番号で行う。
- 印刷ページ番号は印刷設定（用紙・余白・倍率）で変わるため、Excel の内容自体からは一意に決まらない。そのため本リストでは位置特定に使っていない（写真に写っていた透かしのページ番号は目安にすぎない）。
